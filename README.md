# Arash Bulk Pricing — قیمت‌گذاری گروهی آرش

افزونه رایگان و متن‌باز برای تغییر گروهی قیمت محصولات ساده و وارییشن‌های ووکامرس؛ با رابط فارسی، فیلتر محصولات، افزایش و کاهش قیمت، گردکردن و تقویم شمسی.

## دانلود و نصب

1. از [بخش Releases](https://github.com/arashashrafii/wordpress-plugin-arash-bulk-pricing/releases/latest) فایل `arash-bulk-pricing-0.2.25.zip` را دانلود کنید.
2. در وردپرس، افزونه‌ها ← افزودن ← بارگذاری افزونه، ZIP را نصب و فعال کنید. WooCommerce باید فعال باشد.
3. از منوی ووکامرس ← قیمت‌گذاری گروهی وارد شوید.

نصب از سورس: محتویات پوشه `plugin/` را در `wp-content/plugins/arash-bulk-pricing/` قرار دهید. ZIP خودکار کل مخزن، بسته نصب مستقیم افزونه نیست.

## مجوز و وضعیت

GPL-2.0-or-later؛ استفاده، تغییر و بازتوزیع مطابق مجوز آزاد است. سورس PHP خواناست و هیچ قفل دامنه، کلید فعال‌سازی، اتصال به راست‌چین یا نیاز به ionCube ندارد. کتابخانه تقویم مجوز MIT خود را حفظ می‌کند.

توسعه تجاری متوقف شده است؛ تضمین پشتیبانی یا به‌روزرسانی منظم وجود ندارد. ابتدا روی نسخه آزمایشی فروشگاه و با پشتیبان داده‌ها بررسی کنید.

## محدودیت‌ها

ورود و خروجی Excel، تاریخچه بازگردانی پس از ذخیره و قیمت‌گذاری خودکار ندارد. صفحه‌بندی فعلی پس از دریافت محصولات انجام می‌شود؛ کارایی کاتالوگ بزرگ تضمین نشده است.
