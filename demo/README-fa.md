# محیط آزمایشی مدیریت گروهی قیمت محصولات آرش

دموی عمومی از یک نصب WordPress و WooCommerce روی VPS استفاده می‌کند. `demo.raynab.ir` هم صفحهٔ معرفی محصولات را نشان می‌دهد و هم مسیر `/arash-bulk-pricing/` را برای ورود به دموی افزونه ارائه می‌کند. هر دو مسیر در همان WordPress اجرا می‌شوند؛ برای هر محصول وردپرس یا زیردامنهٔ جدا ساخته نمی‌شود.

تصویر PHP بر پایهٔ تصویر رسمی WordPress و PHP 8.2 است. نسخه آزاد افزونه هیچ نیازی به ionCube یا فعال‌سازی لایسنس ندارد.

در استقرار عمومی، Nginx Proxy Manager همین یک میزبان را به WordPress وصل می‌کند. دیتابیس MariaDB نیز روی همان VPS و در کانتینر جدا با volume پایدار اجرا می‌شود. صفحهٔ معرفی به‌صورت فایل ایستا از افزونهٔ اختصاصی محیط دمو سرو می‌شود؛ کانتینر وب جداگانهٔ قبلی حذف شده است.

## راه‌اندازی محلی

1. در `.env` دو رمز تصادفی مستقل برای `DB_PASSWORD` و `DB_ROOT_PASSWORD` قرار دهید.
2. `docker compose up -d --build` را اجرا کنید.
3. نصب WordPress را روی نشانی محلی انجام دهید.
4. فقط دادهٔ آزمایشی بسازید؛ از اطلاعات واقعی فروشگاه استفاده نکنید.


## وضعیت نسخه آزاد و استقرار

صفحات معرفی در `portal/index.html` و `portal/product-demo.html` شامل لینک دانلود ۰.۲.۲۵، مجوز آزاد و اعلام توقف توسعه هستند. برای استقرار، این دو فایل را در مسیر افزونه درگاه دموی موجود جایگزین و پوشه افزونه قیمت‌گذاری را با محتویات `plugin/` به‌روز کنید. افزونه محدودسازی دمو و نقش `demo_operator` باید فعال بمانند؛ افزونه فروشی آزاد، مستقل از محدودسازی فقط‌خواندنی سرور است.

در ۱۰ نوامبر ۲۰۲۶ استقرار تازه انجام نشد: سرور کلید SSH پیکربندی‌شده را نپذیرفت. صفحات و نسخه نصب‌شده سایت زنده هنوز تأیید نشده‌اند. پس از رفع دسترسی، نسخه افزونه، بارگذاری صفحات، لینک دانلود و رد درخواست ذخیره برای نقش دمو بررسی شوند. به‌روزرسانی سورس مخزن به‌تنهایی سایت زنده را تغییر نمی‌دهد.
